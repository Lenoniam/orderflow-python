# OrderFlow — Python

Sistema de vendas e pedidos desenvolvido em Python para uma loja de roupas.

## Funcionalidades

- Catálogo de produtos por categoria
- Carrinho de compras
- Seleção de tamanho e quantidade
- Finalização de pedidos
- Formas de pagamento
- Atualização do status do pedido
- Relatório financeiro
- Banco de dados SQLite criado localmente

## Como executar

```bash
python main.py
```

O banco `loja_vendas.db` é criado automaticamente na primeira execução e não deve ser versionado.
